## Rulings and choices
- R16: `coverage: Coverage | null` is an extra `SummaryInput` field, computed by the CLI (`coverageFor`) from the 261313 core's own statusHistory (this and the previous month), so no previous core is needed. Difference shown as a signed range.
- Headings inside a summary are `###`; `appendSection` adds `## <heading>` and replaces a same-heading section on a re-run (idempotent). `sectionHeading` builds "Added 12 Dec: 189 round of 10 Dec 2026" / "...: SkillSelect data as at 30 Nov 2026" from `today`, so a round and a new month on the same day get separate sections.
- A revision names its month from the path `data/raw/<month>/`; shows rows before/after and "published recap affected" (or "no published recap affected").
- Page reads shown only above 225 (`> 0.9 * budget`, budget null falls back to 250). Build `WARNING` lines listed verbatim minus the label.
- `previewBase` is the preview origin (`previewOrigin(project, branch)`: Cloudflare alias, 28 chars); null drops the Preview section. Sample links: recap page, spotlight, 261313, 254499.
- Image `blobBase` is an input (src may not contain the old name "landfall"; `no-old-name.test.ts`). Alt text escapes `|`, `[`, `]`.
- Invitations held use `leastText` ("under 286" for a masked previous), state previous floor 0 reads "no count of 20 or more".
