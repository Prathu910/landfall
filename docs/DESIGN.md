# Product experience, v0.2

The redesign makes the report itself the product demonstration. The landing page's pool, points and timeline tabs use working controls rather than a static product screenshot. Forest ink, warm white, mint accents, DM Sans and Instrument Serif form the visual language. The report has a structured workspace navigation, a distinct personal summary and compact interactive tools.

Design research: [Linear](https://linear.app/) for hierarchy, product demonstrations and progressive detail; [Resend](https://resend.com/) for clear feature framing and deliberate motion. These informed the approach, not a copied layout or brand.

[Mantine 9](https://mantine.dev/) provides searchable comboboxes, date calendars, number inputs, radio/checkbox choices, segmented controls, progress, tooltips, accordion and mobile drawer. [Motion](https://motion.dev/docs/react) provides section entrances, feature-tab and form-step transitions, responsive chart changes and score transitions. Both use the visitor's reduced-motion preference. Hover/focus states remain visible without requiring animation.

Charts use native SVG with meaningful labels and published-count tooltips. Monthly figures also have an accessible table. All report sections remain available in print, including collapsed glossary and policy content. No mock testimonials, fabricated user counts or unsupported prediction claims are used as design decoration.
