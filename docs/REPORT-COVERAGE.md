# Original report coverage

Reviewed against `docs/original-references/landfall-sample.html` on 17 November 2026. The reference is a product and design sketch with illustrative figures, not an authoritative data source. The original files remain unchanged.

The first implementation covered the federal points audit, a submitted 189 pool snapshot, score comparisons, personal dates, state summaries and sources. It did **not** support the entire reference report. Later iterations added verified invitation history, monthly pool history, three visa pool comparisons, credential scenarios, occupation comparisons and preparation tools. Roadmap step 2 (18 November 2026) opens the report with a reality check across 189, 190 and 491, followed by a detail panel for each visa; the old pool and invitation-history sections are folded into the 189 panel. The table below records the remaining boundaries rather than treating the sketch as a completed feature list.

## Data sources

The report reads the per-occupation SkillSelect dataset described in `docs/DATA.md` (snapshot `skillselect-2026-10-31`, 493 occupations, 479 with published EOIs). Every occupation is searchable in the explorer, the check and the comparison picker. The report's sections use the same shapes as before, through `src/lib/data/legacy.ts`: three current visa score distributions, twelve directly published monthly 189 submitted totals, and the six most recent official 189 rounds. The TypeScript importer in `scripts/import/` reads only the displayed text, keeps `<20` as the bounded interval 0–19, and never queries unsuppressed counts or custom count expressions. For the original 11 occupations it reproduces the earlier data exactly.

For example, the directly published October 2026 ICT Business Analyst totals are 7,774 submitted EOIs for 189, 11,607 for 190, and 11,263 for state/territory nominated 491. These pools overlap. For this occupation the current October round table does not list a cut-off; the historical November 2024 table does list 95. Carrying that historical value forward as the latest result would be misleading.

Occupations with no published EOIs at all keep the points check: the reality check says the data is too limited to compare and the visa panels are left out. A points-only check ("other", or no occupation in the snapshot) says the user chose a points check only, with "Points only" chips (ruling S15). A failed occupation load says the data could not be loaded, with a "Not loaded" 189 chip. An occupation with no 189 pool still shows its 190 and 491 panels. While an occupation's file loads, the scorecard headline and a single placeholder in place of the panels say "Loading published data…"; sections that need the detail file show their own loading state, or say it could not be loaded.

Monthly totals and score distributions are checked for consistency for every generated occupation: each published aggregate must fall within the sum of its published score intervals. Absence from an invitation table remains distinct from an observation of zero.

The dataset also holds EOI statuses, Month Submitted cohorts, per-state pools and invitations, and invited profile slices. The reality check (step 2) uses the statuses, cohorts and national invitations; the state outlook (step 3) uses the per-state pools and invitations, plus the curated state rules and imported state and federal occupation lists described under "State rules" in `docs/DATA.md`. The invited-profile slices are not used yet. Note the coverage-window finding in `docs/DATA.md`: the monthly 189 trend partly reflects the dashboard's coverage filling up since late 2024, not only pool growth.
