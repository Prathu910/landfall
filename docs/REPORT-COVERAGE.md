# Original report coverage

Reviewed against `docs/original-references/landfall-sample.html` on 17 November 2026. The reference is a product and design sketch with illustrative figures, not an authoritative data source. The original files remain unchanged.

The first implementation covered the federal points audit, a submitted 189 pool snapshot, score comparisons, personal dates, state summaries and sources. It did **not** support the entire reference report. This iteration adds verified invitation history, monthly pool history, three visa pool comparisons, credential scenarios, occupation comparisons and preparation tools. ## Data sources

The report reads the per-occupation SkillSelect dataset described in `docs/DATA.md` (snapshot `skillselect-2026-10-31`, 493 occupations, 479 with published EOIs). Every occupation is searchable in the explorer, the check and the comparison picker. The report's sections use the same shapes as before, through `src/lib/data/legacy.ts`: three current visa score distributions, twelve directly published monthly 189 submitted totals, and the six most recent official 189 rounds. The TypeScript importer in `scripts/import/` reads only the displayed text, keeps `<20` as the bounded interval 0–19, and never queries unsuppressed counts or custom count expressions. For the original 11 occupations it reproduces the earlier data exactly.

For example, the directly published October 2026 ICT Business Analyst totals are 7,774 submitted EOIs for 189, 11,607 for 190, and 11,263 for state/territory nominated 491. These pools overlap. For this occupation the current October round table does not list a cut-off; the historical November 2024 table does list 95. Carrying that historical value forward as the latest result would be misleading.

Occupations with no published 189 pool, or no published EOIs at all, keep the points check and say plainly that no pool comparison is available. While an occupation's file loads, the pool, rounds and comparison sections say "Loading published data…".

Monthly totals and score distributions are checked for consistency for every generated occupation: each published aggregate must fall within the sum of its published score intervals. Absence from an invitation table remains distinct from an observation of zero.

The dataset also holds EOI statuses, Month Submitted cohorts, per-state pools and invitations, and invited profile slices. The report does not use them yet; steps 2 and 3 of `docs/STRATEGY.md` will. Note the coverage-window finding in `docs/DATA.md`: the monthly 189 trend partly reflects the dashboard's coverage filling up since late 2024, not only pool growth.
